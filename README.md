# showers-to-flowers
inspired by the quote "April showers bring May flowers" 🌸

A small interactive browser game where the player moves a rainy cloud to help a plant grow into a flower.

built with Django and JavaScript.

## About

In this game, the player controls a cloud moving left and right across the sky.  
Rain falls from the cloud, and the goal is to water the plant below until it blooms.

## Features (current version)

- Move cloud using arrow keys <- and ->
- Continuous rain generation
- Rain follows cloud position
- Basic rain physics (gravity simulation)
- Plant growth system:
  - 🌱 seed
  - 🌿 sprout
  - 🌸 flower
